# Title

Wrapped annual report view and `/api/wrapped` routes

## Summary

Implement `GET /api/wrapped` (years) and `GET /api/wrapped/:year` (thin over issue 16's
functions) plus the `/wrapped/:year` page per DESIGN.md §11.3: the 8-card annual report with
year selector, listening-clock mini chart, and print stylesheet as the v1 export mechanism.

## Context

Wrapped is the emotional payoff page and the only print-designed surface. Artwork thumbnails
appear later (issue 27) — this issue renders initials-avatars as the permanent fallback.

## Scope

- Routes in `src/server/routes/stats.ts`; `src/web/pages/Wrapped/` (page, cards, `Clock.tsx`,
  print css); `i18n/{en,ja}/wrapped.json`.

## Detailed Requirements

1. Routes: `/api/wrapped` → years asc; `/api/wrapped/:year` → §11.3 payload; year param zod
   int 1900-2100; out-of-data year → 404 envelope.
2. Page/navigation: `/wrapped` redirects to the latest year; year selector (horizontal
   chips, keyboard navigable) from the years endpoint. Empty library (`years: []`) →
   `/wrapped` and `/wrapped/:year` render the shared EmptyState with import CTA (no
   redirect). Unknown year with non-empty years → NotFound state with the selector still
   shown. Timezone handling reuses issue 15's `getDisplayTimezone` (via the stats layer —
   no new helper).
3. Cards (grid `repeat(auto-fit, minmax(320px, 1fr))`; order fixed):
   1. Hero: big year numeral, plays, minutes+coverage badge, distinct artists/tracks.
   2. Top artists (5): rank, initials-avatar (deterministic bg color from artist-name hash),
      replaced by artwork when `artworkId` is non-null. Normative loading rule: the artwork
      route stays bearer-token-protected like every API route (plain `<img src>` cannot send
      the header), so the page fetches image bytes via `apiFetch` as a Blob and renders an
      object URL (allowed by the §13.3 CSP `img-src blob:`), revoked on unmount. Fallback to
      initials on any fetch error.
   3. Top tracks (5): rank, title, artist, plays.
   4. Top genres (3; i18n key `wrapped.topGenres`, consistent with DESIGN §11.3): name +
      share bar; card hidden entirely when no genre data.
   5. Listening clock: 24 vertical bars (SVG, no d3), local-hour labels 0/6/12/18, tooltip
      per bar; day-precision exclusion note when such events exist in the year.
   6. Firsts & records: first/last play (localized datetime + track), busiest day, max
      same-track day.
   7. New discoveries: count + top 3 artist names.
   8. Sources: horizontal stacked bar of per-source plays share with legend.
4. Print (`@media print`): nav/selector hidden, cards reflow to A4 portrait 2-col, dark
   theme forced light, page break avoided inside cards, footer "generated by musicmap" +
   year. A "Print / Save as PDF" button calls `window.print()`.
5. Empty year impossible by construction (years endpoint), but a year with only
   day-precision events renders clock card in its "insufficient data" variant (plays exist,
   clock empty → message).

## Acceptance Criteria

- [ ] Route tests: years golden; wrapped 2019 golden (all fields incl. clock array,
      discoveries); 404 for 1999; auth 401.
- [ ] Component tests: all 8 cards render from fixture payload; genre card hidden when
      `topGenres` empty; clock insufficient-data variant; artwork blob path (mocked apiFetch
      returning blob) swaps initials → img and revokes the object URL on unmount; empty
      library renders EmptyState.
- [ ] T7: hostile artist/track/genre strings render as inert text in cards, SVG clock
      tooltips, and the selector (DOM assertions; no dangerouslySetInnerHTML).
- [ ] Print stylesheet assertions: `@media print` rules exist for two-column card flow,
      `.card { break-inside: avoid }`, nav/selector/print-button hidden, light theme forced
      (custom properties overridden), and footer text `generated by musicmap` + year.
- [ ] Route security: 401 without token on both wrapped endpoints.
- [ ] Year selector keyboard operable; deep link `/wrapped/2019` works after reload.
- [ ] en/ja coverage (all card labels/records phrasing); screenshots (en+ja) + a print-to-PDF
      sample attached to PR.

## Validation

`npm test`, lint, typecheck; manual print preview check.

## Dependencies

16-stats-extended, 17-web-shell-i18n.

## Non-goals

Artwork fetching/queueing (27 — only the render slot + blob loader land here), image/PNG
export (v1 non-goal), sharing links.
